# Recai — DevSecOps & Agentic Engineer

High-school student from Türkiye building practical software around Linux,
backend systems, DevSecOps, self-hosting, and AI tooling.

I like turning ideas into reliable, automation-friendly software: APIs, CLIs,
TUIs, agents, infrastructure tools, local-first apps, and embedded systems.
Frontend work is welcome when it serves the product, but my center of gravity is
the backend and the terminal.

## What I work with

- Python, Go, TypeScript/JavaScript, Bash, and SQL
- Linux across Ubuntu, Fedora, and Arch
- Docker, Docker Compose, Git, SSH, networking, and homelab servers
- Ollama, local LLMs, AI agents, MCP, RAG, and orchestration
- Raspberry Pi, ESP32, Arduino-compatible boards, and embedded Linux
- Early-stage security, penetration-testing, and reverse-engineering research

## Engineering style

I prefer clean, typed, modular code with clear boundaries, meaningful names,
consistent APIs, and minimal dependencies. I think about scalability,
maintainability, error handling, developer experience, and cross-platform use
from the beginning—with Linux as the primary target.
