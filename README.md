# Recai (rebehzat)

Independent reverse engineering and embedded Linux research.

Current project: [Samsung SM-J700F Shannon S310 CBD replacement](https://github.com/rebehzat/samsung-s310-cbd-replacement), an open-source ARM32 drop-in replacement for Samsung's `cbd` / `cpboot-daemon` on the Galaxy J7 (`j7elte`).

Topics include Samsung Shannon S310 baseband research, modem boot loaders,
Linux device drivers, Android internals, ARMv7 systems, and reproducible
on-device debugging.
